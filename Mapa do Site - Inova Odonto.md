Mapa do Site — Inova Odonto

«Arquitetura definida a partir do "briefing.md". O objetivo é construir um site multipágina profissional, de fácil navegação, visualmente organizado e adequado a uma clínica odontológica.»

1. Estrutura global

index.html       → HOME
sobre.html       → SOBRE A CLÍNICA
servicos.html    → SERVIÇOS
equipe.html      → NOSSA EQUIPE
contato.html     → CONTATO

As cinco páginas devem ser documentos navegáveis independentes, e não apenas seções de uma única landing page.

Navegação principal

- Início
- Sobre a clínica
- Serviços
- Nossa equipe
- Contato
- CTA destacado: Agendar pelo WhatsApp

Elementos globais reutilizáveis

- Header
- Logotipo da Inova Odonto
- Navegação desktop
- Menu mobile
- Botão principal de WhatsApp
- Cards de serviços
- Cards de profissionais
- Seções de CTA
- Footer
- Links para redes sociais
